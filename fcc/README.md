# Outputs

These reference outputs were generated with random seed `2026`. Running
`python run_all.py` regenerates them.

## Model comparison

`model_comparison.csv` contains:

| Column | Description |
|---|---|
| `model` | Candidate model name |
| `parameters` | Number of fitted parameters |
| `cv_nll_mean` | Mean five-fold held-out negative log likelihood |
| `cv_nll_se` | Standard error across test folds |
| `log_likelihood` | Full-sample log likelihood |
| `aic` | Akaike information criterion |
| `bic` | Bayesian information criterion |
| `ks_statistic` | Kolmogorov-Smirnov distance |

The primary selection criterion is `cv_nll_mean`; lower is better.

## Selected model

`selected_model.json` contains the selected distribution, fitted parameters,
bootstrap intervals, data summary, normalization rule, and diagnostics.

## Figures

- `g_valuation_fit.png`: empirical histogram, KDE reference, and fitted density.
- `g_model_diagnostics.png`: CDF, quantile, and cross-validation diagnostics.
